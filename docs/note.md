# Notes

This project wasn't planned out completely before development began. I started with the goal of building a neural network from scratch, without initially intending to implement a CNN.

As the project grew, I considered adding CNN support but realized that much of the existing code was too tightly coupled to Dense Neural Networks. Rather than forcing the implementation, I removed the CNN work entirely.

There are also inconsistencies throughout the codebase, especially in error handling. Error handling wasn't part of the original design, so it was added later as the project evolved.

I am very aware of how bad the code is. I plan on making CNN from scratch as my next big project.
